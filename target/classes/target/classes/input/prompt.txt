Olá Claude. Imagine que você já foi um desenvolvedor sênior e agora é o grande engenheiro de software do universo.
Você irá me auxiliar a implementar os fontes que estou criando para um gerador de códigos fontes DAO.
Esse meu projeto está sendo idealizado em Java por opção minha e já está estruturado em jdk 8 para compilar e rodar em windows.
Mais abaixo irei te fornecer a estrutura dos diretórios do projeto, dos fontes e de todo arquivo que faz parte do todo.
Meu projeto é compilado pelo maven. Minha ideia é que o jar resultante seja chamado puramente, sem argumentos e forneça 
como output arquivos fonte Java que integrarão os meus projetos também Java.
A minha motivação é parametrizar a criação de arquivos DAO para os meus vários projetos Java.
Como possuo muitos projetos que possuem classes de objetos, classes abstratas, interfaces e classes DAO todas com nomes e tipos de variáveis bem peculiares, 
pensei que seria mis fácil se eu tivesse um projeto GeradorDAO que me auxiliasse a gerar esses fontes de maneira mais fácil.
Antes de explicar o que eu quero, vou falar da estrutura do projeto.

** estrutura de diretórios do projeto e suas explicações **
input: folder que irá conter o arquivo txt ingerido automaticamente em runtime pela aplicação
output: folder que receberá os fontes criados pela aplicação, cujos nomes e diretrizes serão explicitados pelo arquivo contido dentro do diretório input e pela lógica do projeto
res: folder que inicialmente não será usada, mas poderá servir para segurar logo da aplicação caso eu deseje incluir GUI a ela ou incluir ela à outra aplicação que contém GUI
src: localização dos fontes java que você irá me auxiliar.
target: local de compilação do maven
src\br\com: é o sub-sub-diretório que contém de fato os fontes que você irá me auxiliar a implementar

** outros arquivos do projeto **
compila.bat: .bat que ordena a compilação do projeto pelo maven para ganhar tempo
pom.xml: você sabe pra que isso funciona
run.bat: idem
